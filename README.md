## 先想清楚：你要的是带宽，还是线路质量

美国西岸机房到国内的物理延迟摆在那里，正常在 150ms 到 200ms 之间，谁也没法把这条物理距离抹掉。在这个前提下，能优化的只有两件事：

- **路由绕不绕**：走优化线路（如 AS9929、CMI）基本是国内出口直连洛杉矶，普通国际线路高峰期容易绕日本、绕香港。
- **带宽跑不跑得满**：标称 200Mbps 的“国际大带宽”，晚上跑出 20Mbps 也很常见；优化线路带宽小，但能稳定跑满。

如果你要的是个人博客、企业展示站、轻量 API，延迟和稳定性优先，选线路；如果你要的是存文件、做镜像站、跑下载分发，带宽和流量单价优先，选大带宽。这两类需求在雨云的美国节点里对应的是两个不同机房，下面分开说。

## 洛杉矶一区和二区，不是同一套网络

这是最容易买错的地方。雨云把美国节点放在洛杉矶，但分成两个机房，线路定位完全不一样。

### 洛杉矶一区：国际大带宽，走 AS4837

一区的定位就是“带宽给够、价格压低”。官方和第三方文档里反复提到的特性是接入超大带宽、适合大流量业务，比如下载站、私人网盘、文件分发。代价是延迟比二区还要高一些，按第三方选购指南的说法，整体比二区再高个 30–50ms，晚高峰跑不满是常态。

### 洛杉矶二区：联通 AS9929 + 移动 CMI 双线

二区走的是精品网，联通侧 AS9929、移动侧 CMI，电信去程走 163 骨干网直连。第三方测评里给的实测数据大致是：联通约 157ms、移动约 158ms、电信约 172ms，港澳台和东南亚节点可以压到 147ms 左右；本地移动宽带 Ping 的平均值约 182ms，测试过程中基本没有丢包。二区还有两个实际差异——**可以加购 200G 防御的独立 IP**，以及**官方没有为这个区域开通备份功能**，需要站点备份的要自己解决。

一句话总结：建站、面向国内用户的业务选二区；放文件、跑流量选一区。真要拿一区开小站，页面首屏会比二区慢半拍，这一点提前有心理准备就行。
